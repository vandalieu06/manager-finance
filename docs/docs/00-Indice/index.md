## Contexto
La app que se sta desarrollando es una app de gestión financiera personal para analizar los gastos mensuales que se obtienen de tiquets de productos y sirve como control para el usuario con objetivo de detectar donde y porque gasta más y permitir tener un control financiero mejor.
## Estructura App
La apilicacion esta siendo desarollada en react native, ten en ucenta sus limitaciones en el diseño y estrcutura.
La app estará compuesta por las siguientes paginas:
1. Home: mini dashboard + de 6 elementos (gráfico)
	1. Al hacer click en el gráfico, muestra una screen con los datos de esa seccion del gráfico
	2. navbar principal con los links pertinetens
2. configuración
	1. Modificar perfil de usuario
	2. Ajustes basicos de la app
	3. info basica de app (vers, etc)
	4. Ayuda
	5. Extraer Datos
3. Escanear facturas
	1. Botones para cambiar el tipo de subida (manual / foto (subir solo archivo))
	2. btn de historial de facturas (se puede visualizar la subidas y el proceso de las subidas)
4. Productos
	1. Dashboard de los productos comprados con filtrados, rankings, division de supers, categoria de productos, etc.
