# 1.1. Introducción

Lumen es un sistema de gestión de finanzas personales centrado en una aplicación móvil. Su objetivo principal es ayudar al usuario a registrar, consultar y comprender mejor sus gastos cotidianos, ofreciendo una visión clara sobre cómo se distribuye su dinero y en qué tipo de productos concentra una mayor parte de su consumo.

La idea del proyecto nace de una necesidad habitual: muchas personas no tienen una visión ordenada de sus gastos porque el registro manual resulta lento, repetitivo o poco cómodo. Lumen propone una solución centrada en el móvil, con una interfaz sencilla y visual, para que el usuario pueda consultar su información financiera de forma rápida.

El proyecto contempla dos vías de registro de información. Por un lado, el usuario puede introducir productos de forma manual. Por otro, se plantea el procesamiento de tickets o facturas mediante reconocimiento óptico de caracteres e inteligencia artificial, con el objetivo de extraer productos, importes y comercios de forma automatizada.

La solución desarrollada se compone de varios módulos: una app móvil con Expo y React Native, un backend en Go con API REST y PostgreSQL, un servicio OCR en Python/Flask para procesar tickets, y una landing page desarrollada con Astro. La app móvil valida la experiencia principal del usuario; el backend define la persistencia, autenticación e integración con OCR; y el servicio OCR aporta la extracción automática de información desde imágenes.

## 1.1.1. Explicación de qué trata

La aplicación se estructura como una herramienta de apoyo para la economía personal. Permite al usuario acceder a un resumen de su actividad, consultar productos, filtrar gastos, revisar facturas y configurar preferencias básicas de la aplicación.

En el estado actual, Lumen cuenta con las siguientes áreas principales:

- Inicio, donde se muestran tarjetas resumen y accesos a estadísticas.
- Productos, donde se listan gastos o productos de demostración con filtros por categoría, marca, precio y búsqueda textual.
- Scan, donde se captura una factura con cámara, se envía la imagen y se permite añadir productos manualmente.
- Configuración, donde se agrupan opciones de perfil, preferencias, permisos y otras secciones de la aplicación.
- API backend, donde se definen transacciones, categorías, tags, balance, autenticación y almacenamiento de facturas.
- Servicio OCR, encargado de procesar imágenes de tickets y extraer información estructurada.
- Landing page, utilizada como página de presentación del producto.

La memoria diferencia entre funcionalidades ya implementadas, datos de demostración y elementos pendientes de integración completa. Esta distinción permite presentar el alcance real del proyecto sin confundir prototipo funcional con producto final desplegado.

## 1.1.2. Propósitos y objetivos que se quieren alcanzar

El propósito general del proyecto es desarrollar una aplicación móvil que ayude a mejorar la gestión de gastos personales mediante una experiencia clara, visual y fácil de utilizar.

Los objetivos principales son:

- Diseñar una interfaz móvil sencilla y comprensible para consultar información financiera.
- Permitir el registro y consulta de productos o gastos cotidianos.
- Clasificar los gastos en categorías para facilitar su interpretación.
- Ofrecer filtros y búsquedas que permitan localizar productos concretos.
- Implementar el flujo de captura de facturas como base para la integración con OCR e IA.
- Permitir la revisión de facturas y productos detectados o introducidos manualmente.
- Diseñar una API backend que permita persistir usuarios, transacciones, categorías, tags, facturas y productos.
- Integrar un servicio OCR capaz de procesar tickets y devolver información estructurada.
- Documentar la instalación y configuración de todos los componentes del sistema.
- Crear una landing page de presentación del producto Lumen.
- Aplicar una identidad visual coherente basada en el concepto de Lumen como herramienta que aporta claridad sobre el dinero.
- Utilizar tecnologías actuales de desarrollo móvil, como React Native y Expo.
- Documentar el proyecto de forma que pueda ser entendido, mantenido y ampliado.

Como objetivo formativo, el proyecto permite aplicar conocimientos de desarrollo de interfaces, diseño de software, organización de proyectos, documentación técnica, control de versiones y análisis de requisitos.
