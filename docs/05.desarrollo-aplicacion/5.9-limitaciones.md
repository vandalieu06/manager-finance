# 5.9. Limitaciones del estado actual

- **Sin persistencia:** todos los datos locales (facturas, categorías, preferencias) se pierden al recargar la aplicación.
- **Sin backend real:** las pantallas funcionan con datos demo; `authenticatedFetch` está preparada pero no conectada.
- **OCR no integrado:** el envío de facturas apunta directamente al servicio OCR; no pasa por autenticación ni por el backend Go.
- **Sin pruebas automatizadas:** no hay tests unitarios ni de integración en la app móvil.
