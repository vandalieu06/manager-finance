# Documentación del proyecto Lumen

Esta carpeta contiene la documentación completa del proyecto Lumen. La documentación principal está organizada según el índice de la memoria, en carpetas numeradas del `00` al `12`.

Cada carpeta contiene el capítulo completo y, además, archivos separados para cada subapartado del índice. De esta forma se conserva una versión exhaustiva del capítulo y una navegación granular punto por punto.
