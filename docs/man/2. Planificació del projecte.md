
La planificación del proyecto se ha definido siguiendo una metodología **ágil e iterativa**, dividiendo el desarrollo en tareas programadas con entregas periódicas, lo que permite ajustar prioridades y aplicar mejoras continuas a lo largo del ciclo de desarrollo. Este enfoque facilita la revisión constante del progreso y la detección temprana de problemas técnicos, asegurando que cada etapa del proyecto cumpla con los objetivos funcionales y de calidad establecidos.

Se han establecido **sprints de dos semanas**, en los que se asignan tareas específicas a los integrantes del equipo. Cada sprint concluye con una revisión del estado del proyecto y la planificación de los próximos pasos, permitiendo ajustar tiempos y recursos según la complejidad de cada tarea.

### 2.1. Temporización del proyecto

El proyecto se ha organizado en etapas secuenciales y paralelas, con entregas periódicas cada dos semanas. La temporalización se centra en:

- Inicialización del repositorio y configuración básica del entorno de desarrollo.
- Definición de los modelos de datos en SQL y su implementación mediante Gorm.
- Investigación e integración de tecnologías de OCR para la captura de productos desde tickets.
- Aprendizaje y adaptación del lenguaje Go para el desarrollo del backend.
- Desarrollo de la API y pruebas iniciales de integración con frontend y bases de datos.
- Implementación de tareas futuras relacionadas con funcionalidades avanzadas y optimización de procesos.

Este enfoque permite asegurar que cada componente se construya de manera incremental, garantizando que el sistema evolucione de forma estable y funcional durante todo el desarrollo.

### 2.2. Recursos y materiales

Para llevar a cabo el proyecto, se han identificado los siguientes recursos y materiales:

- **Hardware:** laptops personales de los integrantes, VPS con Ubuntu para el despliegue y pruebas.
- **Software y herramientas de desarrollo:** Docker para contenerización, Postgres y SQLite como bases de datos, herramientas de control de versiones como Git y repositorios en GitHub.
- **Documentación y referencias:** documentación oficial de Go, React Native, Gorm y librerías relacionadas, así como recursos de aprendizaje de OCR y frameworks de IA.
- **Entorno de colaboración:** Obsidian para documentación interna, herramientas de comunicación y coordinación, y herramientas de planificación de tareas.

Estos recursos aseguran que el equipo pueda desarrollar, probar y mantener la aplicación de manera eficiente y organizada.

### 2.3. Tecnologías escogidas para el desarrollo

La selección tecnológica se ha realizado considerando **rendimiento, escalabilidad y compatibilidad entre componentes**, así como la experiencia del equipo. Las principales tecnologías utilizadas son:

- **Lenguajes y frameworks:** Go para el backend, Gorm para ORM, HTTP + Chi para servidores y rutas, Python para tareas de IA y OCR, Flask para microservicios auxiliares.
- **Inteligencia artificial y OCR:** PaddleOCR, OpenCV, OpenRouter, Ollama y herramientas de IA como ChatGPT, Gemini y Minimax.
- **Bases de datos:** PostgreSQL para la gestión principal de datos, SQLite para almacenamiento local y pruebas.
- **Frontend móvil:** React Native con Expo para desarrollo multiplataforma.
- **Infraestructura y despliegue:** Docker para contenerización de servicios, VPS con Ubuntu para alojamiento de backend y bases de datos.
- **Otros servicios:** Stripe para gestión de pagos y suscripciones.
- **Documentación y planificación:** Obsidian para la gestión de documentación interna, Mermaid para diagramas de flujo y organigramas, y OpenCode para control de calidad y pruebas.

Esta combinación de tecnologías permite integrar de manera eficiente **backend, frontend, bases de datos y servicios de inteligencia artificial**, garantizando un sistema robusto, escalable y adaptable a las necesidades de los usuarios.
