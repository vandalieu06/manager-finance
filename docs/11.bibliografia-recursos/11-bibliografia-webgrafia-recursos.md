## 11.4. Recursos internos del proyecto

- Repositorio `mobile-app`: fuente de verdad de pantallas, navegación, componentes, hooks y stores locales.
- Repositorio `api-main`: fuente de verdad del backend Go, entidades GORM, endpoints y migraciones.
- Repositorio `ocr-processor`: fuente de verdad del servicio OCR Flask, tests y proveedores LLM.
- Repositorio `landing-page`: fuente de verdad de la landing Astro.
- Carpeta `docs/final`: copies finales utilizados para la memoria.
- Carpeta `docs/figma`: especificaciones de pantallas y sistema visual.
