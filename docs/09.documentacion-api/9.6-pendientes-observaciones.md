# 9.6 Pendientes y observaciones

1. **App móvil ↔ Backend Go**: La app aún no consume el backend Go real. `authenticatedFetch` está definida pero las pantallas trabajan con datos demo locales.
2. **`/api/factura` vs `/api/transactions`**: La app envía a `/api/factura` con campo `factura`; el backend Go recibe en `POST /api/transactions` con campo `image`. Es necesario unificar el contrato.
3. **OCR sin autenticación**: El servicio OCR no requiere autenticación. Si se expone públicamente debe protegerse (API key o proxy a través del backend Go).
4. **Token de prueba**: `"test-admin-uid"` permite desarrollo sin Firebase real. No usar en producción.
5. **Seguridad**: No committear `.env` ni archivos JSON de Firebase Admin SDK. El repositorio incluye `.env.sample` como plantilla.
6. **`init.sql` eliminado**: La fuente de verdad del esquema es `AutoMigrate` de GORM.
