# 9.1.3 Códigos de estado globales (Backend Go)

| Código | Significado |
|--------|-------------|
| `200` | OK |
| `201` | Creado |
| `204` | Eliminado (sin contenido) |
| `400` | Solicitud incorrecta / datos inválidos |
| `401` | No autorizado / token inválido |
| `404` | Recurso no encontrado |
| `500` | Error interno del servidor |
