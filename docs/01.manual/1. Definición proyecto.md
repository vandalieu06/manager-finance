# 1. Introducción

En este proyecto se presenta el desarrollo de una aplicación móvil orientada a la gestión de finanzas personales. La aplicación tiene como objetivo principal ayudar a los usuarios a registrar, analizar y comprender mejor sus gastos cotidianos, permitiendo así disponer de una visión más clara sobre el uso de sus recursos económicos.

La idea principal del proyecto surge de la necesidad de contar con una herramienta sencilla que permita registrar compras de manera rápida y automatizada. Para ello, la aplicación incorpora la posibilidad de registrar productos manualmente o bien extraerlos directamente a partir de fotografías de tickets de compra. Este proceso se realiza mediante tecnologías de reconocimiento óptico de caracteres (OCR) combinadas con herramientas de inteligencia artificial, que permiten identificar los productos presentes en los tickets y almacenarlos en el sistema.

Gracias a esta funcionalidad, el usuario puede obtener un registro detallado de sus compras y visualizar posteriormente información relacionada con su consumo. La aplicación permite analizar los gastos mediante gráficos y estadísticas que facilitan la interpretación de los datos y ayudan a detectar patrones de consumo o identificar en qué tipos de productos se concentra una mayor parte del gasto.

Uno de los aspectos relevantes del proyecto es que la aplicación está diseñada para funcionar tanto en modo offline como en modo online. En el modo offline, el usuario puede continuar utilizando la aplicación para registrar productos y consultar su información financiera sin necesidad de conexión a internet. Por otro lado, cuando se dispone de conexión, se habilitan funcionalidades adicionales relacionadas con el uso de inteligencia artificial para el procesamiento automático de tickets y la generación de análisis más avanzados.

A lo largo de la documentación se explicarán los diferentes aspectos que forman parte del desarrollo del proyecto, incluyendo el diseño de la aplicación, sus principales funcionalidades, la arquitectura del sistema y las tecnologías utilizadas. El objetivo es describir de manera clara el funcionamiento de la aplicación y las decisiones técnicas adoptadas durante su desarrollo.

Mediante este proyecto se pretende aplicar los conocimientos adquiridos durante el proceso formativo, especialmente en el ámbito del desarrollo de aplicaciones, la gestión de datos y la integración de tecnologías actuales como el reconocimiento de texto y la inteligencia artificial. Además, el desarrollo de esta aplicación permite poner en práctica habilidades relacionadas con el diseño de software, la estructuración de proyectos y la resolución de problemas técnicos.
