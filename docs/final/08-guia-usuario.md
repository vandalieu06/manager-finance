# 8. Guía de usuario

Esta guía explica el uso de las pantallas principales de la aplicación móvil Lumen en su estado actual.

## Inicio de sesión

Al abrir la aplicación, el usuario accede a la pantalla de login. Debe introducir email y contraseña. Si las credenciales son correctas, la aplicación redirige a la zona principal con navegación inferior.

[captura pantalla login]

## Pantalla Home

La pantalla Home muestra un resumen general de la actividad financiera. Incluye tarjetas de información, últimas actualizaciones y una tarjeta de análisis con acceso a estadísticas.

[captura pantalla home]

## Consulta de productos

En la pestaña Productos, el usuario puede consultar una lista de productos registrados como datos de demostración. La pantalla permite buscar por texto y aplicar filtros por categoría, marca o rango de precio.

[captura pantalla productos]

Al seleccionar un producto, se abre una pantalla de detalle donde se muestra nombre, marca, precio, categoría, fecha e identificador.

[captura pantalla detalle producto]

## Escaneo y registro de facturas

En la pestaña Scan, el usuario puede elegir entre dos modos:

**Modo foto**

Simula el flujo de captura de una factura. La aplicación muestra una previsualización dibujada y permite simular la subida. El sistema devuelve un estado de éxito, incompleto o error.

[captura pantalla scan modo foto]

**Modo manual**

Permite seleccionar una factura existente y añadir un producto introduciendo nombre, importe, comercio y categoría.

[captura pantalla scan modo manual]

## Revisión de facturas

La pantalla de detalle de factura muestra el estado de la factura, una previsualización, los campos detectados y los productos vinculados. Si la factura está pendiente o incompleta, el usuario puede validarla o denegarla.

[captura pantalla detalle factura]

## Estadísticas

La pantalla Stats presenta métricas de ingresos, beneficios y variación. En la versión actual, estos datos son demostrativos y sirven para validar la presentación de estadísticas.

[captura pantalla stats]

## Configuración

Desde Configuración, el usuario puede acceder a secciones como Perfil, Preferencias, Notificaciones, Categorías, Datos e Información.

[captura pantalla configuración]

En Perfil se pueden modificar datos locales del usuario.

[captura pantalla perfil]

En Preferencias se puede seleccionar idioma, moneda y alternar el control de tema.

[captura pantalla preferencias]
